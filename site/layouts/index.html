how a change ships

  1. git pushto GitHub
  2. GitHub Actionsbuilds the Hugo site into an image
  3. GHCRstores the image
  4. committhe new image tag lands back in Git
  5. Argo CDsees the change and syncs the cluster

how a request gets here

  1. youask for muskeg.dev
  2. Cloudflareedge and DNS
  3. Cloudflare Tunneloutbound-only connection from the cluster
  4. Traefikverified TLS with a cert-manager wildcard
  5. NGINXserves this page

under the hood

  • Talos Linux three control-plane VMs on Proxmox, sharing a virtual IP. No SSH, no shell, managed through an API.
  • Argo CD manages everything, including itself, through an app-of-apps.
  • External Secrets pulls credentials from 1Password, so no secret ever lives in Git.
  • Renovate opens pull requests when charts and images have new versions.
